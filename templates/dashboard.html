File Upload Guidelines

✅ Requirements
  • File formats: CSV (.csv), Excel (.xlsx, .xls)
  • Max file size: 16MB
  • Column headers: First row must contain column names
  • Data rows: At least 2 rows of data required
⚠️ Common Issues to Avoid
  • Empty columns: Remove empty columns from your Excel file
  • Merged cells: Unmerge all cells before uploading
  • Special characters: Avoid special characters in column names (use letters, numbers, underscore)
  • Multiple sheets: Only the first sheet will be processed
  • Formulas: Excel formulas will be converted to their calculated values
💡 Best Practices
  • Use clear, descriptive column names (e.g., "Sales Amount" instead of "SA")
  • Keep numeric data as numbers (no currency symbols or commas)
  • Use consistent date formats (YYYY-MM-DD recommended)
  • Remove any summary rows or totals at the bottom
  • Ensure data starts from row 1 (no title rows above headers)
